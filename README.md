# 몸놀이 오락실 (BODY ARCADE)

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요
- **한 줄 소개:** "내 몸이 곧 게임기!" 웹캠 하나로 AI가 전신 동작을 실시간으로 인식합니다. 컨트롤러나 설치 없이 브라우저에서 바로 즐기는 체감형 운동 게임 오락실입니다.
- **누구를 위한 앱인가:**
  - 실내에서 놀면서 몸을 움직이고 싶은 어린이·청소년과 가족
  - 비싼 게임기나 전용 센서 없이 체감형 게임을 하고 싶은 사람
  - 체육 수업, 쉬는 시간, 행사에서 함께 할 몸풀기 활동이 필요한 교사와 진행자
- **어떤 상황에서 쓰는가:**
  - 비 오는 날이나 집에 있을 때처럼 운동량이 부족한 순간
  - 친구나 가족과 화면 하나로 2인 대결을 할 때
  - 공부·업무 중 짧게 몸을 움직이며 쉴 때
  - 갤럭시·노트북(Chrome), 아이폰(Safari)에서 주소 하나로 바로 실행할 때

## 주요 기능
| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. **AI 전신 동작 인식 조작:** 팔, 다리, 몸 기울기, 점프, 쪼그려 앉기, 스쿼트를 실시간으로 판정 | 카메라 미리보기와 인식 상태 표시(🟢 몸 인식 중 / 🔴 몸이 안 보여요), 자세 안내 문구("다리까지 보이게 서너 걸음 뒤로 서주세요"), 인식 감도 3단계(둔감·보통·민감) | **MediaPipe Tasks Vision 0.10.14의 PoseLandmarker**(pose_landmarker_lite 모델, 33개 신체 랜드마크)를 브라우저에서 직접 실행하는 온디바이스 AI입니다. 기기가 지원하지 않으면 호환 모드로 자동 전환합니다. |
| 2. **체감형 미니게임 4종:** 히어로 비행, 네온 러너, 스쿼트 줄다리기, 포즈 벽 통과(아래 상세 표 참고) | 게임 고르기 카드, Canvas 게임 화면, 결과 화면(🎉 신기록/첫 기록, 🔁 다시 하기, 처음으로) | 클라이언트 JavaScript 게임 엔진이 동작 판정, 점수와 콤보 계산, 승패 판정을 처리합니다. |
| 3. **계정·2인 대결·랭킹** | 로그인·회원가입 창, 내 계정(가입일·플레이 횟수), 👤 1인 / 👥 2인 모드 선택, 🏆 이 기기 랭킹 | **Web Crypto API(PBKDF2)** 로 비밀번호를 해시해 **localStorage** 에 저장합니다. 입력값을 검증하고, 5번 틀리면 계정을 30초 동안 잠급니다. |

### 게임 4종 상세
| 게임 | 몸 동작(카메라) | 1인 | 2인 대결 | 카메라 없이 |
| --- | --- | --- | --- | --- |
| 🕊️ **히어로 비행** | 팔을 날개처럼 펴고 몸을 기울이면 좌우 이동, 팔을 올리고 내리면 위아래 이동 | 노을 하늘의 링 통과(파란 링은 부스트) | 같은 하늘에서 링과 별을 더 많이 먹는 레이스 | 화면을 끌어서 조종(방향키 / WASD) |
| 🦘 **네온 러너** | 제자리 점프로 장벽 넘기, 쪼그려 앉아 드론 피하기 | 네온 도시 질주 | 위 트랙은 1P, 아래 트랙은 2P, 끝까지 살아남기 | 위쪽 탭은 점프, 아래쪽 꾹은 숙이기(↑↓ / W·S) |
| ⬇⬆ **스쿼트 줄다리기** | 스쿼트 1번이 줄 한 번 당기기, 빠를수록 세게 당김, 연속 동작은 "영차! 🔥" 콤보 | 30초 안에 로봇 CPU와 대결 | 1P는 왼쪽, 2P는 오른쪽, 30초 승부 | 화면 빠르게 탭(스페이스바) |
| 🙆 **포즈 벽 통과** | 다가오는 벽 구멍 모양대로 팔과 다리까지 맞추기. 포즈는 만세, T자, 한쪽 팔(좌/우), 쪼그리기, 별 모양, 한쪽 다리 들기(좌/우) | 벽 부수기 | 같은 벽을 누가 먼저 맞추나(1P 왼쪽 구멍, 2P 오른쪽 구멍, 벽 15개) | 버튼으로 자세 선택(1P 키 1~8 / 2P Q~I) |

**더 만든 기능:**
- **손을 쓰지 않는 메뉴 조작:** 손을 화면 위 버튼에 몇 초 올려두면 선택됩니다. 카메라 앞에 선 채로 캐릭터 선택과 게임 시작을 할 수 있습니다.
- **캐릭터 5종:** 네온맨(빛으로 만든 러너), 햄찌(볼빵빵 햄스터), 냥냥이(날쌘 고양이), 로보-X(제트 로봇), 티라노(꼬마 공룡). 모습만 다르고 실력은 같아서 공정하게 대결할 수 있습니다.
- **카메라 없이 하는 모드(터치·키보드):** 모든 게임을 1인과 2인 모두 지원합니다. 카메라가 없거나 권한을 거부한 환경에서도 플레이할 수 있습니다.
- **게스트 모드:** 로그인 없이 1인 플레이를 할 수 있고, 로그인하면 2인 대결과 랭킹이 열립니다.
- **오리지널 EDM 엔진:** 음원 파일 없이 Web Audio API로 음악을 실시간 합성합니다(사이드체인 효과 포함). 저작권 걱정이 없습니다.
- **성능 자동 조절:** 고화질 효과를 ON/OFF할 수 있습니다. 기기가 느려지면 "부드럽게 돌아가도록 고화질 효과를 껐어요"라고 알리고 자동으로 끕니다.
- **꼼꼼한 예외 처리:**
  - 카메라 권한 거부, 카메라를 다른 앱이 쓰는 중, 연결 끊김, 앱 안 미리보기나 파일로 열기, https가 아닌 주소에서 각각 해결 방법을 안내합니다.
  - AI 모델 로딩 실패 시 "와이파이 대신 데이터(LTE)로" 바꾸거나 터치 모드를 쓰라는 대안을 제시합니다.
  - 시크릿 모드라서 저장이 막혔을 때 알려 줍니다.
  - 몸이 화면을 벗어나면 "🙈 몸이 안 보여요!" 안내를 띄웁니다.
- 회원가입 입력 검증: 닉네임은 한글·영문·숫자·밑줄(_)만 써서 2~10자로 정해야 하고, 이미 있는 닉네임인지 확인합니다. 비밀번호는 4~24자이며, 한 번 더 입력해 오타를 막습니다. 조건에 맞지 않으면 무엇이 잘못됐는지 바로 안내합니다.
- 기록: 게임별 개인 최고 기록과 신기록 알림(이전 기록 비교), 기기별 랭킹을 제공합니다.
- 전체화면 모드, 모바일·태블릿·PC 반응형 화면을 지원합니다.

## 기술 스택
- **프론트엔드:** HTML5, CSS3, Vanilla JavaScript로 만든 단일 HTML 파일(약 210KB)이고, Canvas 2D로 렌더링합니다. 폰트는 Pretendard, Black Han Sans, Orbitron을 씁니다.
- **AI:** Google MediaPipe Tasks Vision `PoseLandmarker`(pose_landmarker_lite, float16)를 CDN(jsDelivr / unpkg)으로 불러와 브라우저에서 추론합니다.
- **백엔드:** 별도 서버가 없는 정적 웹앱(Serverless)이고 GitHub Pages로 배포합니다. 서버 비용이 0원이고, 카메라 영상이 외부로 나가지 않습니다.
- **데이터(어디에, 무엇을):** 브라우저 **localStorage** 에 계정(닉네임, PBKDF2 해시 비밀번호), 가입일, 플레이 횟수, 게임별 최고 기록과 랭킹을 저장합니다. **카메라 영상은 저장하거나 전송하지 않고** 기기 안에서만 분석합니다.

## 실행 방법
1. 저장소를 받습니다: `git clone https://github.com/hight44kimtaeyoung/body-arcade.git` 후 `cd body-arcade`
2. 로컬 서버를 실행합니다: `npx serve . -l 3000` 또는 `python -m http.server 3000`. 카메라와 암호화 API는 보안 출처(https 또는 localhost)에서만 동작하므로 파일을 더블클릭해서 열면 안 됩니다.
3. Chrome(아이폰은 Safari)에서 `http://localhost:3000/hight666.html`에 접속합니다.
4. **📷 카메라로 시작**을 누르고 카메라를 허용합니다. 카메라에서 두세 걸음 떨어져 서면 됩니다(네온 러너와 포즈 벽 통과는 다리까지 보이게 서너 걸음). 카메라가 없으면 **👆 카메라 없이**를 누릅니다.

**배포 주소:** https://hight44kimtaeyoung.github.io/body-arcade/hight666.html

## AI 활용 내역
- **사용한 도구:**
  - 개발: Claude, ChatGPT(코드 생성, 디버깅, 문구 작성), GitHub Pages(배포)
  - 앱에 들어간 AI: Google MediaPipe Pose Landmarker(실시간 전신 포즈 추정)
- **주요 프롬프트(그대로 붙여 넣기):**
  ```
  1. 웹캠으로 사람의 전신을 인식해서 컨트롤러 없이 몸으로 조작하는 웹 게임을 만들고 싶어. MediaPipe Pose Landmarker를 써서 설치 없이 HTML 파일 하나로 실행되게 만들어줘. 갤럭시, 아이폰, 노트북에서 모두 돌아가야 해.
  2. 게임을 여러 개 넣은 오락실 형태로 만들어줘. 팔을 펴고 몸을 기울여 나는 비행 게임, 점프와 쪼그려 앉기로 피하는 러너 게임, 스쿼트로 줄을 당기는 줄다리기, 벽 구멍 모양대로 포즈를 맞추는 게임을 넣어줘.
  3. 한 화면에서 왼쪽은 1P, 오른쪽은 2P로 두 사람이 동시에 인식되는 2인 대결 모드를 추가해줘. 캐릭터 5종을 고를 수 있게 하고, 모습만 다르고 능력은 같게 해줘.
  4. 카메라가 없거나 권한을 거부해도 할 수 있도록 모든 게임에 터치·키보드 모드를 만들어줘. 카메라 권한 거부, 몸이 안 보임, AI 모델 로딩 실패 같은 상황마다 아이도 이해할 수 있는 쉬운 안내 문구를 보여줘.
  5. 로그인·회원가입을 만들어줘. 서버 없이 localStorage에 저장하되 비밀번호는 Web Crypto PBKDF2로 해시하고, 5번 틀리면 30초 잠금, 닉네임 검증, 기기별 랭킹과 최고 기록을 넣어줘.
  6. 음원 파일 없이 Web Audio API로 신나는 EDM 배경음악을 실시간으로 만들어줘. 사이드체인 느낌도 넣어줘.
  ```
- **AI가 만든 것 / 사람이 고친 것:**
  - **AI가 만든 것:** 게임 엔진과 Canvas 렌더링 코드, MediaPipe 연동과 포즈 판정 함수 초안, 게임 4종의 기본 로직, Web Audio EDM 합성 코드, 로그인·랭킹 저장 코드, UI 레이아웃 초안
  - **사람이 고친 것:**
    - 게임 기획(게임 종류, 포즈 목록, 1인/2인 규칙, 30초 제한, 벽 15개, 등 밸런스)을 결정했습니다.
    - 직접 해 보니 사람마다 동작 크기가 달라 오인식이 생겨서 인식 감도를 3단계(둔감·보통·민감)로 나눴습니다.
    - 카메라 앞에서 마우스를 누르기 불편해서, 손을 버튼에 올려두면 선택되는 조작 방식을 넣었습니다.
    - 아이폰·앱 내 브라우저·파일로 열기에서 카메라가 막히는 문제를 찾아 환경별 안내 문구와 터치 모드로 해결했습니다.
    - 저사양 휴대폰에서 끊김이 생겨 고화질 효과 자동 끄기와 호환 모드를 추가했습니다.
    - 낱자 닉네임("ㄱ", "ㅏ") 차단, 비밀번호 5회 오류 시 잠금, 시크릿 모드 저장 실패 안내 등 예외 상황을 직접 찾아 보완했습니다.
    - 안내 문구를 아이도 이해할 수 있는 쉬운 말로 다듬었습니다.
- **결과를 확인한 방법:**
  - 노트북(Chrome), 갤럭시(Chrome), 아이폰(Safari)에서 게임 4종을 1인과 2인 모드로 모두 직접 플레이했습니다.
  - 여러 명이 키, 거리, 조명을 바꿔 가며 감도별 인식을 확인했습니다.
  - 카메라 권한 거부, 몸이 화면 밖으로 나감, 와이파이 끊김, 시크릿 모드 같은 오류 상황을 일부러 만들어 안내 문구가 제대로 나오는지 확인했습니다.
  - 회원가입(중복 닉네임, 잘못된 입력), 로그인 5회 실패 잠금, 신기록 저장과 랭킹 갱신을 테스트했습니다.
  - 카메라 없는 모드에서 터치와 키보드 조작이 모든 게임에서 되는지 확인했습니다.

## 팀원 역할
(이름·학번 없이 역할만)
- **기획:** 서비스 콘셉트("내 몸이 곧 게임기"), 게임 4종과 포즈 설계, 캐릭터 기획, 1인/2인 규칙과 밸런스 설계
- **프론트엔드:** Canvas 게임 화면, 메뉴·결과 UI, 반응형·전체화면, 손 올려두기 조작, 터치·키보드 모드, EDM 사운드
- **백엔드:** MediaPipe 포즈 인식 연동과 동작 판정 로직, PBKDF2 계정 보안, localStorage 기록·랭킹 저장, GitHub Pages 배포
- **검증:** 여러 기기와 브라우저에서 테스트, 인식 감도 조정, 오류 상황 재현과 안내 문구 점검

## 아쉬운 점과 다음에 할 일
- **아쉬운 점**
  - 계정과 랭킹이 기기 안(localStorage)에만 저장되어 다른 기기와 공유되지 않고, 브라우저 데이터를 지우면 사라집니다.
  - 조명, 역광, 카메라 각도에 따라 인식 정확도가 달라집니다.

  - 저사양 기기에서는 고화질 효과가 제한됩니다.
  - 처음 실행할 때 AI 모델을 내려받아야 해서 네트워크가 느리면 시작이 늦어집니다.
